# ---------------------------------------------------------------------
# Third-party repo needed:
#   codium -> download.vscodium.com; scripts/provision.sh installs
#             packages/third-party/vscodium.repo before the packages step,
#             otherwise `codium` silently drops out of the install list and
#             Mod+e (the $editor binding) is broken on a fresh machine.
#
# NOT installable from Fedora repos — provisioned separately:
#   zellij               -> GitHub release binary into ~/.local/bin
#   lazygit              -> `go install github.com/jesseduffield/lazygit@latest`
#   oh-my-zsh + its zsh-autosuggestions / zsh-syntax-highlighting
#                        -> git clones (the dnf versions do not satisfy
#                           ZSH_PLUGINS, so we match what this machine runs)
#   Zen browser          -> flatpak, see packages/flatpak.txt
#   JetBrainsMono Nerd Font -> scripts/install-fonts.sh (no Nerd glyphs in
#                           Fedora's jetbrains-mono-fonts; polybar/rofi/ghostty
#                           all require it)
